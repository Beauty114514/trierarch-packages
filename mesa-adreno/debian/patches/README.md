# Debian Mesa patch queue

This directory is intentionally separate from Kali's `debian/patches`.
`debian/build.sh` applies every `*.patch` here after obtaining Kali's Mesa
source package and before running `dpkg-buildpackage`.

Only patches tested against the pinned Kali Mesa source version belong here.
Do not copy Arch packages or Arch `PKGBUILD` files into a Debian guest.

The current `0001-trierarch-kgsl-wayland.patch` was generated by comparing the
Kali `mesa_26.1.6.orig.tar.xz` source with the Mesa tree that was actually
compiled and verified in the Kali chroot. It includes the ifdevs KGSL changes
and Trierarch's Wayland/KGSL adjustments as one atomic patch for now.
